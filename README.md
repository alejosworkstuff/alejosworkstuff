- **[AI Story Generator](https://ai-stories-ashy.vercel.app/)** ([repo](https://github.com/alejosworkstuff/ai-stories)): Vercel AI SDK streaming, RAG on Neon/pgvector, rate limits, and a small eval set.
- **[mini-ecommerce](https://mini-ecommerce-nextjs-psi.vercel.app/)** ([repo](https://github.com/alejosworkstuff/mini-ecommerce-nextjs)): Clerk, Redis/Prisma, Sentry, Vitest and Playwright in CI.

I optimize for clarity, typed contracts, and recoverable failures.
